Пример страницы с Adaptive Widget

Это демонстрационная страница: откройте консоль-виджет справа внизу — ИИ-агент отвечает из QA-базы сервера и строит знания из текста страницы.

Список специальностей:

  • Радиосвязь, радиовещание и телевидение
  • Информационные системы
  • Разработка приложений для мобильных устройств
  • Программирование в компьютерных системах

Для работы запустите сервер: cd server && node server.js, админка — на http://127.0.0.1:3000/admin.
