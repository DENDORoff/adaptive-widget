ПРОДУКТ

Adaptive Widget —
ИИ-поддержка как часть вашего сайта

Чат-виджет, который сам подстраивается под дизайн сайта, отвечает по данным страницы, переводит на оператора и присылает уведомления — в одном файле и без волшебства.

🎨 Автодизайн

Считывает палитру и шрифт сайта

🤖 ИИ-агент

Ответы на основе текста сайта

🧑‍💻 Операторы

Handoff + уведомления

📊 Админка

Чаты, статистика, настройки

ПРОБЛЕМА

Клиенты уходят, когда не получают ответ

Сайты теряют обращения, потому что обратная связь спрятана в формах и письмах: вопрос сгорает, менеджер отвечает через день, а дизайн чужих виджетов выбивается из стиля.

❗ Обычные виджеты

Не совпадают с брендом · отвечают шаблонами · нет статистики · вопросы теряются.

✅ Наше решение

Дизайн = ваш сайт · ответы = ваши данные · оператор рядом · всё в админке.

РЕШЕНИЕ

Один скрипт + один сервер

1

Страница

виджет читает текст, заголовки, контакты, alt — и красится под дизайн

2

Backend

Node.js без npm: агент, чаты, QA, уведомления, «Муха»

3

ИИ-модель

Ollama локально или любой OpenAI-совместимый API

4

Вы

админка на /admin: оператор, настройки, статистика

CORS открыт — работает с любого домена. SSE стримит сообщения в реальном времени.
ДЕМО

Живой пример на сайте колледжа

Виджет отвечает про специальности, поступление и документы — данные берутся прямо с сайта. Тёмная/светлая тема и цвета кнопок меняются следом за дизайном страницы.

window.ADAPTIVE_WIDGET = {
  siteName: 'Высший колледж электроники и коммуникации',
  backend: 'http://127.0.0.1:3000/api',
  provider: 'auto', model: 'qwen2.5:3b',
  teaser: 'Спросите о поступлении, специальностях или документах'
};
ВОЗМОЖНОСТИ

Что закрывает продукт

🤝 Операторы и handoff

Кнопка «Позвать оператора», статусы чата, ответ из админки, письмо клиенту при офлайне.

🔔 Уведомления

SMTP (Яндекс/Gmail/Mail.ru) и Discord: новый чат, запрос оператора, оценка, нерешённый вопрос.

📈 Статистика

Активные чаты, нерешённые, средняя оценка 1–5, популярные запросы.

🧪 Экспериментальная «Муха»

Чат по коннектому мозга мухи и 3D-нейроны из NeuPrint — файл нейромаркетинга.

ТЕХНОЛОГИИ

Стек

Виджет

Vanilla JS · Shadow DOM · ноль зависимостей

Backend

Node.js (http, ws-free SSE) · JSON Store · без npm install

ИИ

OpenAI-совместимый API: Ollama, OpenAI, OpenRouter, Groq, Mistral, custom

Интеграции

SMTP, Discord, NeuPrint (three.js r128), Laravel API

Тесты: jsdom (логика) + puppeteer-core (вьювер, анимации, флаги). Запуск: npm test.
БЕЗОПАСНОСТЬ

Приватность и контроль

Данные на вашем сервере

Чаты и знания хранятся локально в server/data — никуда не уходят.

Выбираете модель

Ollama — всё локально и бесплатно; облачные модели — только по вашей воле.

Токен админки

Панель оператора закрыта паролем из config.json, можно переиздавать.

XSS-защита

Весь текст экранируется, контент сайта — в знания, а не в HTML.
