Как подключить

Три шага — и виджет работает на вашем сайте

Запустите сервер поддержки

Один файл, Node.js 18+, без npm-зависимостей. Сервер обрабатывает чаты, ИИ-агента, уведомления, «Муху». В комплекте — админка для операторов.

cd server && node server.js

Добавьте два тега на любую страницу

Скрипт автоматически подбирает дизайн под ваш сайт и появляется в правом нижнем углу.

<script>
window.ADAPTIVE_WIDGET = {
  siteName: 'Название сайта',
  backend: 'http://127.0.0.1:3000/api',
  provider: 'auto',
  model: 'qwen2.5:3b'
};
</script>
<script src="adaptive-widget.js"></script>

Настройте в админке

Откройте /admin — настройте ИИ-модель, добавьте FAQ, настройте SMTP/Discord для уведомлений, управляйте операторами и флагами.

FAQ

Сколько стоит?

Виджет и сервер — бесплатно. Вы платите только за модель (Ollama — бесплатно локально; OpenAI — ~$0.002 за вопрос).

Можно ли без нейросети?

Да. QA-база и передача оператору работают без модели. ИИ просто отключается из настроек.

Можно ли в iframe / на другой домен?

Да. Виджет встраивается как скрипт с любого домена, backend — CORS открыт.
