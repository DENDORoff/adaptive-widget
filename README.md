# Adaptive Widget — ИИ-агент поддержки для сайта

Адаптивный чат-виджет, который сам подстраивается под дизайн сайта (цвет, шрифт, тёмная тема),
отвечает на вопросы клиентов на основе данных сайта, умеет переводить на оператора,
отправлять уведомления (email / Discord) и имеет экспериментальную вкладку «Муха»
(чат и 3D-визуализация коннектома мозга плодовой мухи через NeuPrint).

Содержимое репозитория:

| Путь | Что это |
|---|---|
| `widget/adaptive-widget.js` | сам виджет (один файл, без внешних зависимостей для чата) |
| `server/` | backend поддержки (Node.js **без npm-зависимостей**): чаты, агент, email, Discord, NeuPrint, конфиг |
| `admin/` | панель оператора и настройки: чаты, статистика, база инструкций, конфиг, разделы сайта, новости |
| `landing/` | лендинг продукта (открыть `landing/index.html`) |
| `presentation/` | презентация (слайды стрелками, `presentation/index.html`) |
| `docs/` | развёрнутые инструкции |
| `README.md` | этот файл — быстрый старт и справка |

## 1. Как это работает

```
Браузер клиента                      Ваш / наш сервер (Node.js)
┌──────────────────┐   /widget.js   ┌─────────────────────────┐
│ adaptive-widget  │ ─────────────> │ server.js :3000         │
│ • собирает текст │  /api/init     │ • /api/chat/*  чаты      │
│   и знания сайта │  /api/chat/…   │ • /api/agent  ИИ-агент   │
│ • красится под   │  /api/flags    │ • /api/fly/*  «Муха»     │
│   ваш дизайн     │  /api/faq      │ • email / Discord        │
│ • флаги оператор │  /api/kb      │ • config.json            │
│   / муха / email │                │ • админка /admin         │
└──────────────────┘                └─────────────────────────┘
```

Виджет читает контент страницы (заголовки, текст, ссылки, контакты), индексирует его и через
backend отвечает вопросами «по делу». ИИ-модель подключается через OpenAI-совместимый API
(Ollama, OpenAI, OpenRouter, Groq, Mistral или свой). Даже без модели работают ответы из
«Вопрос-Ответ» (QA-базы) и передача на оператора.

## 2. Быстрый старт

### 2.1. Запустите backend

```bash
cd server
# при необходимости скопируйте и поправьте пример конфига
cp config.example.json config.json
node server.js
```

Сервер поднимется на `http://127.0.0.1:3000`, админка на `http://127.0.0.1:3000/admin`.

> Сервер не требует `npm install` — только Node.js (проверено на 18+).

### 2.2. Подключите виджет на любую страницу

```html
<script>
window.ADAPTIVE_WIDGET = {
  siteName: 'Название сайта',
  backend: 'http://127.0.0.1:3000/api',   // адрес сервера поддержки
  endpoint: 'http://127.0.0.1:3000/api',  // совпадает с backend
  provider: 'auto',
  model: 'qwen2.5:3b'                      // модель на вашем Ollama / другом API
};
</script>
<script src="adaptive-widget.js"></script>
```

**Есть только одно обязательное условие:** если у вас сервер поддержки — `backend` должен
указывать на него. Без backend виджет работает как «автономный» чат напрямую к
OpenAI-совместимому API (`endpoint`), но без операторов, «Мухи», FAQ-чипов и ссылок из базы.

Виджет сам определит дизайн страницы: текст/кнопка, тёмная тема, шрифт, радиусы — и перекрасит
себя. Если нужно принудительно — задайте `aiStyle`/палитру, см. `docs/CONFIG.md`.

### 2.3. Админка

- **Чаты** — общение с посетителями, переключение «ИИ ↔ оператор», закрытие, оценка диалога.
- **Статистика** — активные чаты, сайты, ответы, нерешённые запросы, средняя оценка.
- **Данные и инструкции** — глобальная база инструкций для ИИ-агента.
- **Сайт / Новости** — для сайта на Laravel (см. `docs/SITE_INTEGRATION.md`).
- **Настройки** — провайдер ИИ, модель, SMTP, Discord, флаги (операторы / «Муха» / email).

Первого запуска: если в `config.json` задан `adminToken`, админка спросит его один раз
и сохранит в localStorage.

## 3. Конфигурация виджета (window.ADAPTIVE_WIDGET)

Все поля имеют значения по умолчанию, задавать можно только нужные.

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `siteName` | string | из `<title>` | имя сайта, показывается в шапке виджета |
| `position` | string | `right` | кнопка чата: `left` / `right` |
| `backend` | string | `` | адрес сервера поддержки (`http://host:3000/api`). Вкл. операторов, «Муху», QA, статистику |
| `endpoint` | string | Ollama local | OpenAI-совместимый URL модели (на него идут запросы ИИ) |
| `apiKey` | string | `` | ключ для OpenAI/OpenRouter/Groq/Mistral |
| `provider` | string | `auto` | `auto`/`ollama`/`openai`/`openrouter`/`groq`/`mistral`/`custom` |
| `model` | string | по провайдеру | модель (напр. `qwen2.5:3b`, `gpt-4o-mini`) |
| `aiEnabled` | bool | true | вкл/выкл обращения к ИИ-модели (QA-база и оператор продолжают работать) |
| `supportEmail` | string | — | email для фразы «напишите нам» при недоступном бэкенде |
| `instructions` | string | `` | инструкции, добавляемые в системный промпт |
| `askEmail` | bool/str | false | спрашивать email перед чатом (`optional` — можно пропустить) |
| `autoOpen` | bool | true | открывать чат автоматически |
| `teaser` | string | `` | короткая подсказка-плашка перед открытием |
| `aiStyle` | bool | true | авто-подбор палитры под дизайн сайта |
| `vision` | bool | false | описывать картинки на странице |
| `readImages` | bool | true | индексировать `img[alt]` в знания |
| `sound` | bool | true | звук нового сообщения |
| `checkinAfter` | int | 180 | сек бездействия → «вы ещё здесь?» |
| `operatorsEnabled` | bool | true | кнопки оператора. Управляется и с сервера (см. ниже) |
| `flyEnabled` | bool | true | вкладка «Муха». Управляется и с сервера |

Полный справочник флагов и примеры — `docs/CONFIG.md`.

## 4. Флаги: сервер — источник истины

Настройки «Операторы», «Муха» и «Спрашивать email» администратор переключает в админке
(Настройки). Сервер хранит их в `server/config.json` и отдаёт виджету:

- `GET /api/flags` → `{ operatorsEnabled, flyEnabled, askEmail, aiEnabled }`
- `POST /api/init` → то же самое + `chatId` для чата

Виджет в начале работы запрашивает флаги с сервера и **перекрывает ими** всё остальное —
локальный кэш (`localStorage.pw_cfg`) используется только как офлайн-фолбэк, если сервер
недоступен. Это гарантирует: выключили оператора в админке → у клиентов кнопка
«Позвать оператора» сразу исчезает.

## 5. Backend: краткая справка API

Все ответы — JSON. CORS открыт (работает с любого сайта). Админ-эндпоинты требуют
`x-admin-token` (см. `docs/API.md`).

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/config` | публичная часть конфигурации (флаги, вопрос-ответ) — без токена |
| PUT | `/api/config` | сохранение конфигурации (с токеном) |
| POST | `/api/init` | регистрация чата: знания сайта, инструкции, флаги |
| POST | `/api/chat/:id/message` | сообщение в чат (ИИ-агент отвечает) |
| POST | `/api/chat/:id/handoff` | запрос «позвать оператора» |
| POST | `/api/chat/:id/:action` | `ai`/`close`/`resolve`/`rating`, `refresh` (с токеном) |
| SSE | `/api/chat/:id/events` | стрим новых сообщений (виджет слушает) |
| GET | `/api/chats` | список чатов (с токеном) |
| GET | `/api/stats` | статистика (с токеном) |
| GET/POST | `/api/kb` | база инструкций (с токеном) |
| GET | `/api/faq` | популярные вопросы (чипы в виджете) |
| GET | `/api/fly/status` | статус NeuPrint (вкл/выкл, быстрое/офлайн) |
| GET | `/api/fly/neurons` | список демо-нейронов |
| POST | `/api/fly/chat` | вопросы про коннектом (с флагом `flyEnabled`) |
| GET | `/api/fly/neuron/:id` | 3D-данные нейрона |
| POST | `/api/mail/test` | тестовое письмо (с токеном) |

Полное описание запросов и ответов — `docs/API.md`.

## 8. Частые вопросы

**Виджет не отвечает.** Проверьте: модель доступна (Ollama/OpenAI), `endpoint`/`apiKey`
заданы, в логах сервера нет ошибок агента.

**Кнопки «Оператор»/вкладки «Муха» не исчезают после выключения в админке.**
Убедитесь, что `backend` в `window.ADAPTIVE_WIDGET` указывает на этот сервер, и обновите
страницу. Флаги приходят из `GET /api/flags` и перекрывают локальный кэш.

**Хочу свой OpenAI-совместимый API.** Поставьте `provider: 'custom'` и укажите полный
`endpoint` на `/chat/completions`.

**Email-уведомления не уходят.** Демо-режим пишет письма в `server/data/email.log.ndjson`.
Заполните SMTP в админке (Яндекс/Gmail/Mail.ru — пароль приложения) и нажмите
«Отправить тестовое письмо».

**Где хранятся данные?** `server/data/` — чаты, знания, инструкции, outbox писем (создаётся
автоматически, не коммитится). Настройки — `server/config.json`.
